# UPX-IV **AcessMap** - Mapa de Acessibilidade Urbana

## 📌 **Sobre o Projeto**

O projeto **AcessMap** tem como objetivo:

* Exibir um mapa interativo com os ícones personalizados.
* Permitir que usuários marquem pontos de acessibilidade com atributos específicos no mapa.
* Permitir que usuários coloquem título e descrição detalhados sobre os pontos.
* Permitir análise visual sobre acessibilidade.

---

## 🛠️ **Tecnologias Utilizadas**

Tecnologias encontradas no repositório (ajuste se necessário):

* **HTML5 / CSS3 / JavaScript**
* **Node.js**
* **Leaflet.js** (para exibir o mapa)
* **Nodemon** (servidor local para testes e desenvolvimento)
* **SQL** (banco de dados)
* **Git/GitHub**

---

## 🧑‍💼 **Interação do Usuário**

1. Abrir o mapa
2. Navegar e dar zoom
3. Clicar nos marcadores
4. Visualizar informações
